# Introduction

Regular expressions (regex) are patterns used to describe sets of strings. They provide a concise way to define valid sequences of characters and are widely used in programming, text processing, lexical analysis, input validation, and search algorithms.

Instead of explicitly listing every possible valid string, a regular expression defines a language using special operators.

The operators used in this laboratory are:

| Operator | Description |
|----------|-------------|
| `?` | Zero or one occurrence |
| `*` | Zero or more occurrences |
| `+` | One or more occurrences |
| `{n}` | Exactly n occurrences |
| `|` | Alternative (choice between symbols) |
| `()` | Groups expressions together |

According to the assignment requirements, unlimited repetitions generated by `*` and `+` are limited to a maximum of **5 occurrences**.

# Regular Expressions

The following regular expressions were used:

## Expression 1

```
M?N{2}(O|P){3}Q*R+
```

Meaning:

- `M?` → M appears zero or one time
- `N{2}` → exactly two N characters
- `(O|P){3}` → three characters, each being O or P
- `Q*` → zero to five Q characters
- `R+` → one to five R characters

Example generated words:

```
NNOOOQRR
NNPPPQRRRR
NNPPPQQRR
NNPPPQQQQQRRRR
MNNOOOQQQRRRR
MNNPPPRR
```

---

## Expression 2

```
(X|Y|Z){3}8+(9|0)
```

Meaning:

- `(X|Y|Z){3}` → exactly three letters chosen from X, Y or Z
- `8+` → one to five digit 8's
- `(9|0)` → final character is either 9 or 0

Example generated words:

```
YYY89
YYY88889
ZZZ880
YYY8889
XXX89
XXX888889
ZZZ8880
```

---

## Expression 3

```
(H|I)(J|K)L*N?
```

Meaning:

- `(H|I)` → H or I
- `(J|K)` → J or K
- `L*` → zero to five L characters
- `N?` → optional N

Example generated words:

```
IJLLLLN
IKLLLLN
HKLLL
HJLLN
HJLLL
HKLLLL
HJ
IJN
```

# Implementation

The project was implemented in **Python**.

The application dynamically interprets regular expressions instead of generating predefined outputs.

The main function reads the expression from left to right and processes every operator according to its meaning.

The implementation supports:

- Literal characters
- Groups `()`
- Alternatives `|`
- Optional symbols `?`
- Zero or more repetitions `*`
- One or more repetitions `+`
- Fixed repetitions `{n}`

For operators `*` and `+`, the number of repetitions is randomly generated between the allowed minimum and a maximum value of **5**, as required by the assignment.

---

# Algorithm

The generation process follows these steps:

1. Read the regular expression.
2. Process each symbol sequentially.
3. Detect grouped expressions enclosed in parentheses.
4. If alternatives exist (`|`), randomly select one option.
5. Apply repetition operators (`?`, `*`, `+`, `{n}`).
6. Append the generated symbols to the resulting string.
7. Return the final valid word.

This approach allows the same function to generate valid words for different regular expressions without implementing separate logic for each one.
