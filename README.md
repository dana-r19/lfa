2. Theoretical Background
2.1 Finite Automata
A finite automaton is a mathematical model of computation used to represent processes with finite memory. Formally, it is defined as a 5-tuple (Q, Σ, δ, q0, F) where Q represents a finite set of states, Σ represents a finite input alphabet, δ represents the transition function mapping states and input symbols to sets of next states, q0 represents the initial state, and F represents the set of final or accepting states. The term "finite" indicates that the automaton has a limited number of states, meaning it can only remember a finite amount of information about its past inputs.

2.2 Determinism vs Non-determinism
In deterministic finite automata (DFA), for each state and input symbol pair, there exists exactly one transition to a next state. This makes the behavior of the automaton completely predictable. In contrast, non-deterministic finite automata (NDFA or NFA) allow multiple possible transitions for the same state and input symbol. Additionally, NFAs may permit epsilon transitions, which occur without consuming any input symbol. Despite these differences, DFAs and NFAs are equivalent in terms of the languages they can recognize, as any NFA can be converted to an equivalent DFA through the subset construction algorithm.

2.3 Chomsky Hierarchy
The Chomsky hierarchy classifies formal grammars into four levels based on their production rules. Type 0 grammars, also known as unrestricted grammars, impose no restrictions on production rules and generate recursively enumerable languages. Type 1 grammars, or context-sensitive grammars, require that productions have the form αAβ → αγβ where γ is non-empty, meaning replacements can only occur in specific contexts. Type 2 grammars, called context-free grammars, have productions of the form A → γ where A is a single non-terminal, allowing replacements regardless of surrounding symbols. Type 3 grammars, known as regular grammars, are the most restricted and come in two forms: right-linear grammars with productions A → aB or A → a, and left-linear grammars with productions A → Ba or A → a. Regular grammars correspond exactly to the languages recognized by finite automata.

3. Implementation Details
3.1 Variant 22 Specification
The finite automaton for Variant 22 is defined as follows:

Alphabet Σ = {a, b}

Final states F = {q2}

Transition function δ:

δ(q1, b) = {q1, q2}

This automaton is non-deterministic because the transition δ(q1, b) leads to two possible states: q1 and q2 simultaneously.

3.2 Determinism Verification
The implementation checks determinism by verifying that for every state and every input symbol, the transition function yields exactly one next state. If any transition produces multiple states or if any transition is undefined for a given state-symbol pair, the automaton is classified as non-deterministic.

3.3 Conversion from Finite Automaton to Regular Grammar
The conversion from a finite automaton to a regular grammar follows a straightforward algorithm. For each transition δ(A, a) = B where a is a terminal symbol and B is a state, a production rule A → aB is created. Additionally, for each final state F in the automaton, an epsilon production F → ε is added to indicate that the string can end at that state. The start symbol of the grammar becomes the start state of the automaton. This conversion preserves the language recognized by the automaton, meaning every string accepted by the automaton can be generated by the grammar and vice versa.

3.4 NDFA to DFA Conversion Using Subset Construction
The subset construction algorithm converts a non-deterministic finite automaton to an equivalent deterministic one. The algorithm proceeds as follows. First, the initial DFA state is the set containing only the NFA start state. Then, for each unprocessed DFA state which is a set of NFA states, and for each input symbol, the algorithm computes the union of all NFA states reachable from any state in the current DFA state via that symbol. This union becomes a new DFA state. Any DFA state that contains at least one NFA final state becomes a final state in the DFA. The process continues until no new DFA states are generated. Finally, the resulting sets of states are renamed to simpler identifiers like S0, S1, S2 for readability.

3.5 Chomsky Hierarchy Classification
The grammar classifier examines all production rules to determine the grammar type. For Type 3 regular grammars, the implementation checks whether all productions follow either the right-linear form A → aB or A → a, or the left-linear form A → Ba or A → a. For Type 2 context-free grammars, the left-hand side of every production must be a single non-terminal symbol. Type 1 context-sensitive grammars require that productions have the form αAβ → αγβ where γ is non-empty, though a simplified check is implemented for this laboratory. Type 0 unrestricted grammars have no restrictions.

The grammar was classified as Type 3, or regular grammar. This classification is expected because the grammar was derived directly from a finite automaton, and it is well-known that regular grammars and finite automata are equivalent in expressive power. The grammar satisfies all conditions for right-linear regular grammars: every production has either a single terminal, a terminal followed by a non-terminal, or the empty string.
